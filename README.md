# 🚆 RailSathi

### Railway Reservation System using Data Structures

RailSathi is a Python-based Railway Reservation System developed as a Data Structures project. It demonstrates the practical use of different data structures and algorithms through a simple railway reservation application.

## 📌 Features

- 🎫 Book railway tickets
- ❌ Cancel tickets
- 🔎 Search passengers using PNR
- 👥 Manage confirmed passengers
- 🕐 Manage waiting list
- 🔄 Automatically promote waiting passengers after cancellation
- 🔃 Sort passenger records
- 🔍 Binary search for passengers
- 📋 Maintain cancellation history

## 🧩 Data Structures & Algorithms

| Concept | Usage |
|---|---|
| Singly Linked List | Confirmed passenger records |
| Queue | Waiting list |
| Stack | Cancellation history |
| Linear Search | Passenger searching |
| Binary Search | PNR searching |
| Bubble Sort | Sorting passenger records |
